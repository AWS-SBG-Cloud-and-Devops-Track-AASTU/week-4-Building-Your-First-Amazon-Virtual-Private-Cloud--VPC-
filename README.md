## Course Details

**Service:** Amazon Virtual Private Cloud (VPC)

Amazon VPC enables you to launch AWS resources into a logically isolated virtual network that you define, giving you complete control over your virtual networking environment.

### Key concepts learned

- Understanding VPC architecture, including public and private subnets.
- Configuring internet gateways and route tables to manage inbound and outbound traffic.
- Implementing network security using security groups and network access control lists (NACLs).
- Designing a custom virtual network topology for cloud workloads.

### Learning outcome

I gained a foundational understanding of how to configure cloud networking, manage IP addressing ranges, and secure resource communication across subnets using Amazon VPC.
